# Public Domain Bible Datasets (Offline Asset Bundle)

All scripture datasets bundled with "Church Sanctuary" are 100% public domain, open-source (MIT/CC0 code, PD texts), requiring zero royalties, subscription fees, or API tokens.

Translations included:
1. **KJV (King James Version, 1611/1769)** - Public domain worldwide.
2. **WEB (World English Bible, 2000)** - Explicitly released into the Public Domain by Rainbow Missions, Inc.
3. **ASV (American Standard Version, 1901)** - Public domain worldwide.
4. **BBE (Bible in Basic English, 1949/1964)** - Public domain (simplistic 850-word vocabulary English).

Source repository: github.com/scrollmapper/bible_databases
Cross-reference dataset: openbible.info (CC0 / Public Domain)
